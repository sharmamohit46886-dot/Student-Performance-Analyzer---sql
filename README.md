# Student Performance Analyzer

## Project Description
Student Performance Analyzer is a database
management project developed using Oracle SQL
and PL/SQL.

It analyzes student academic performance
based on subject-wise marks.

## Features
- Student record management
- Subject-wise marks storage
- Automatic percentage calculation
- Grade calculation
- Pass/Fail analysis
- Performance reports

## Technologies Used
- Oracle SQL
- PL/SQL
- Database Management System

## PL/SQL Concepts
- Functions
- Procedures
- Cursors
- Exception Handling

## How to Run
1. Open Oracle Live SQL.
2. Copy the SQL file contents.
3. Execute the script.
4. View the student performance reports.
